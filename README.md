## 📖 About

Charcoal Kitchen is a premium BBQ restaurant website designed to showcase the menu and drive orders directly — combining a polished, appetite-driving design with real-world ordering flow through WhatsApp and easy location discovery via Google Maps.

---

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🖼️ | **Hero Section** | Eye-catching intro highlighting featured menu items |
| 📋 | **Full Menu** | Complete menu listing with food images |
| 🔥 | **Special Deals** | Dedicated section for promotions and combo offers |
| 💬 | **WhatsApp Ordering** | Customers can order directly via WhatsApp integration |
| 📍 | **Google Maps** | Embedded map for easy restaurant location discovery |
| 📱 | **Responsive Design** | Fully optimized for mobile, tablet, and desktop |

## 🚀 How to Run Locally

```bash

cd charcoal-kitchen
```

Phir `index.html` ko seedha browser mein open kar do — koi build step ya server ki zaroorat nahi.
